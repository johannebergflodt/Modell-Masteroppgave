# Økonomiske konsekvenser av EU ETS2 Masteroppgave

Dette repositoryet inneholder kode og data brukt i analysen av økonomiske konsekvenser av ETS2 for tungtransportmarkedet. Analysen fokuserer på konkurranseforholdet mellom norske og utenlandske transportaktører og i hvilken grad det stimulerer overgangen til elektriske lastebiler. 

Arbeidet er en del av en masteroppgave i økonomi og administrasjon ved Norges miljø- og biovitenskapelige universitet (NMBU).
